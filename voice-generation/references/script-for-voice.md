# Writing a script for the ear

## Line rules
- One idea per line. 8 to 14 words. Short clauses. A comma where a breath goes.
- Write it the way it is spoken in the chosen dialect, not in formal written Arabic.
- Hook first. Last line is the call to action.
- Foreign names (Claude, TikTok) can stay in Latin letters.
- Numbers: write as words if the voice reads them wrong ("خمسين", not "50").
- Number the lines 1..N. Keep the same numbering in the video scenes.

## Khaleeji spelling cues (Saudi/Gulf style)
| Formal / Egyptian | Khaleeji |
|---|---|
| ماذا / إيه | شو / وش |
| الآن / دلوقتي | الحين |
| كثير / أوي | واجد / مرة |
| أريد / عايز | أبي / أبغى |
| هذا / ده | هذا / هاذا |
| جيد / حلو | زين |
| مجاني / ببلاش | ببلاش / مجاناً |
| فقط / بس | بس |
Use only words the user actually says. Do not force a caricature.

## Egyptian cues
دلوقتي، إزاي، عايز، ببلاش، كده، أوي.

## Voice direction templates (put in Audio Profile, not in the line)
- Khaleeji male: شاب خليجي سعودي، يتكلم باللهجة الخليجية السعودية الطبيعية، حماس وثقة، إيقاع سريع.
- Khaleeji female: شابة خليجية، لهجة خليجية طبيعية، ودودة وواثقة، إيقاع متوسط.
- Egyptian male: شاب مصري، لهجة مصرية عامية طبيعية، حماس، إيقاع سريع.
- Calm narrator (MSA): راوٍ هادئ بالعربية الفصحى المبسطة، إيقاع بطيء، نبرة دافئة.
Change only the mood words for a different feel. Keep it to one or two sentences.

## Pronunciation fixes
- Add short vowel marks only on the one word that is wrong.
- Split a long compound word with a space.
- Spell a foreign word the way it sounds in Arabic letters if the Latin spelling is read badly (كلود).
- Add a comma or full stop for a pause. Do not add words like "pause".
