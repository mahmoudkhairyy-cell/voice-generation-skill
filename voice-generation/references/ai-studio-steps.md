# Google AI Studio: exact steps (phone browser, free)

Checked on a real free Google account on 25 Nov 2026. The screens can change. If a step does not match, describe what you see and follow the nearest button.

Needs: a Google account (any, free). No card.

## Steps to give the user

1. Open `aistudio.google.com/generate-speech` in the phone browser (Chrome). Sign in with Google.
2. Tap the model name (top of the settings, "Run settings"). If the screen is narrow, tap the settings icon first. Choose **Gemini 2.5 Flash Preview TTS**.
   - Do NOT pick "Gemini 3.8 ..." models. On a free account they ask to link a paid key and set up billing. If you see "Link a paid API key", close it and switch model.
3. Tap **Speaker 1** and choose a voice. Male-leaning voices that worked: Achird (friendly, lower middle pitch). Female: Zephyr (bright). Tap the small play arrow next to a voice to hear it first.
4. In **Audio Profile** paste the voice direction Claude wrote (for example: Saudi Khaleeji young man, natural spoken Gulf dialect, confident, fast pace). Leave the Accent menu alone: it only has English accents.
5. Paste one line into the text box of the speech block.
6. Tap **Run**. The player appears at the bottom (about 5 to 10 seconds).
7. Listen. Tap the **download** icon in the player to save the audio. Repeat for the next line.
8. Name the files 1, 2, 3 in order, so they match the script lines.

## Tips

- One line per run keeps timing easy for video. For a long narration, paste up to a paragraph.
- If a word is read wrong: respell it with short vowel marks or phonetically (see `script-for-voice.md`), and run that line again.
- Output is a WAV file. CapCut and phone players open it directly. No conversion needed.
- If the voice sounds Egyptian or MSA instead of Khaleeji: rewrite the line in Khaleeji spelling (see the word list) and make the Audio Profile stronger, then run again. If it still does not sound right, use the CapCut self-record fallback.

## Limits and honesty

- This is a preview model. A secondary source reported that Google will retire the 2.5 preview TTS models on 18 December 2026. After that, check the model list in the same page for another model marked free, and if there is none, use the fallback.
- Daily limits are not shown up front. Two runs in a row worked without any limit message.
- Free-tier text may be used by Google to improve products. No private data in scripts.
